# Decision Intelligence Platform

AI-powered decision analysis platform for comparing choices using structured scoring, analytics, and AI recommendations.

## Tech Stack

### Frontend

* Next.js 16
* TypeScript
* Tailwind CSS
* shadcn/ui
* Zustand

### Backend

* FastAPI
* SQLAlchemy
* SQLite
* Pydantic

## Current Status

* Frontend and backend connected
* Dynamic routes working
* Decision creation flow implemented
* Comparison pages implemented
* Zustand store setup completed
* FastAPI backend running successfully
