# Decision Intelligence Platform

AI-powered platform for structured decision making.

## Features

* Decision comparison
* Weighted scoring
* Pros/cons analysis
* AI recommendations
* Analytics dashboard

## Tech Stack

* Next.js
* FastAPI
* TypeScript
* Tailwind
* SQLAlchemy

## Setup

### Frontend

cd frontend
npm install
npm run dev

### Backend

cd backend
source venv/Scripts/activate
uvicorn app.main:app --reload

## Ports

Frontend:
http://localhost:3000

Backend:
http://localhost:8000
